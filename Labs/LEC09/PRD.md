# 소닉 애니메이션 뷰어 개발 요구사항

## 1. 목적과 근거

`PRE-PRD.md`를 바탕으로, 소닉 스프라이트 시트의 모든 동작을 순서대로 관찰할 수 있는 Python 애니메이션 뷰어를 개발한다. 기능을 작은 단위로 구현하고 검증하며, 각 단계가 별도 커밋이 될 수 있도록 개발한다.

문서 위치와 개발 대상 폴더는 `Labs/LEC09`이다. 이 문서는 개발 명세이며 실제 프로그램 구현이나 커밋 실행을 의미하지 않는다.

## 2. 산출물과 기술 제약

| 항목              | 요구사항                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| 언어              | Python                                                                   |
| 그래픽 라이브러리 | pico2d                                                                   |
| 실행 파일         | `sonic_animation_viewer.py`                                            |
| 코드 구성         | 모든 실행 코드와 동작·프레임 정보를 위 Python 파일 하나에 작성          |
| 이미지            | `sonic-sprite.png`                                                     |
| 경로 처리         | 이미지 경로는 현재 작업 디렉터리가 아닌 Python 파일 위치를 기준으로 계산 |
| 보조 라이브러리   | Python 표준 라이브러리 사용 가능. 추가 그래픽 라이브러리는 도입하지 않음 |

## 3. 요구사항 해석과 기본값

- 원문의 “동작당 5회 재생. 1초 쉬고, 그대로 동작 재생”은 **현재 동작을 5회 연속 재생한 뒤 1초 대기하고 다음 동작을 재생**하는 것으로 해석한다.
- 마지막 동작도 같은 방식으로 5회 재생하고 1초 대기한 뒤 첫 동작으로 돌아간다.
- 대기 중에는 직전 동작의 마지막 프레임을 표시한다.
- 초기 화면 크기는 800 × 600, 기본 재생 속도는 초당 10프레임으로 제안한다. 두 값은 코드 상수로 관리하며 실제 화면 검증 후 조정할 수 있다.
- 동작의 정확한 개수, 이름, 프레임 수, 좌표는 이미지 분석 단계에서 확정한다. 이미지의 한 행을 무조건 하나의 동작으로 간주하지 않는다.

위 재생 해석과 수치 기본값은 원본에 명확히 정해져 있지 않은 사항을 구체화한 개발 기준이다.

## 4. 기능 요구사항

### FR-01. 실행과 초기화

1. 실행하면 pico2d 창을 열고 스프라이트 이미지를 한 번 로드한다.
2. 사용자 입력 없이 첫 동작부터 자동 재생한다.
3. 이미지가 없거나 로드할 수 없으면 대상 경로를 포함한 오류 메시지를 출력하고 열린 창을 정리한 뒤 종료한다.

### FR-02. 동작과 프레임 정의

1. 이미지에 포함된 소닉의 모든 동작을 동작 목록에 등록한다.
2. 각 동작은 고유 식별자, 설명용 이름, 순서가 있는 프레임 목록으로 정의한다.
3. 각 프레임은 원본 이미지의 잘라낼 사각형 좌표와 크기, 표시 위치 보정값을 가진다.
4. 제공 이미지는 프레임 크기와 간격이 불규칙하므로 고정 격자로 일괄 분할하지 않는다. 실제 영역을 확인해 프레임별 좌표를 정의한다.
5. 이미지의 제목, 제작자 문구, 장식 및 소닉 이외의 캐릭터는 재생 대상에서 제외한다. 독립적인 소닉 포즈는 누락하지 않고 필요하면 단일 프레임 동작으로 등록한다.
6. 소닉과 함께 표현된 회전·잔상 효과는 해당 동작 프레임에 포함한다.
7. 동작 순서는 이미지의 위에서 아래, 같은 영역에서는 왼쪽에서 오른쪽을 기본으로 하되, 실제 연속 동작에 맞게 묶어 명시적으로 고정한다.
8. 이미지의 모든 소닉 프레임이 어느 동작에 포함되는지 대조하여 누락과 의도하지 않은 중복을 확인한다.

### FR-03. 동작별 5회 재생

1. 한 동작의 첫 프레임부터 마지막 프레임까지 표시하면 1회 재생으로 센다.
2. 같은 동작을 중간 대기 없이 정확히 5회 연속 재생한다.
3. 마지막 프레임도 다른 프레임과 동일한 기본 표시 시간을 확보한다.
4. 단일 프레임 동작도 프레임 표시 시간 1회분을 한 사이클로 계산해 동일한 규칙을 적용한다.
5. 프레임 진행은 실제 경과 시간을 기준으로 처리하여 렌더링 루프 속도가 재생 속도를 결정하지 않게 한다.

### FR-04. 대기와 전체 순환

1. 현재 동작의 5번째 재생이 완료되면 1초 대기한다.
2. 대기 시간이 지나면 다음 동작의 첫 프레임부터 시작한다.
3. 동작 전환 시 반복 횟수와 프레임 인덱스를 초기화한다.
4. 마지막 동작의 대기가 끝나면 첫 동작으로 돌아가며, 종료 입력이 있을 때까지 전체 순서를 무한 반복한다.
5. 대기 중에도 이벤트 처리와 화면 갱신을 계속한다. 1초 동안 이벤트 처리를 막는 긴 대기 호출을 사용하지 않는다.

### FR-05. 확대 표시와 정렬

1. 소닉을 화면 중앙 부근에 확대 표시한다.
2. 원본 가로·세로 비율을 유지하며 모든 프레임에 공통 배율을 적용한다.
3. 기본 배율은 전체 프레임 중 가장 큰 영역이 화면 가로·세로의 70% 이내에 들어오는 가장 큰 정수 배율로 정한다. 제공 이미지에서는 원본보다 확대되어야 한다.
4. 프레임별 크기 차이 때문에 캐릭터가 불필요하게 흔들리지 않도록 기준점과 보정값을 사용한다. 실제 동작에 포함된 이동은 유지한다.
5. 캐릭터와 동작 효과가 화면 밖으로 잘리거나 인접 프레임·문구가 함께 표시되지 않아야 한다.
6. 배경은 소닉이 잘 구분되는 단색으로 표시하고 매 화면 갱신 시 이전 프레임을 지워 의도하지 않은 잔상을 방지한다.

### FR-06. 종료

1. 창 닫기와 Escape 키로 종료한다.
2. 재생 중과 1초 대기 중 모두 종료 입력에 응답한다.
3. 종료할 때 pico2d 창과 관련 자원을 정리한다.

## 5. 내부 구성과 상태 전환

단일 Python 파일 안에서 상수, 동작 데이터, 초기화, 이벤트 처리, 상태 갱신, 렌더링, 종료 처리를 구분한다. 이미지 로드를 매 프레임 반복하지 않는다.

필수 상태는 현재 동작 인덱스, 현재 프레임 인덱스, 완료한 반복 횟수, 프레임 경과 시간, 대기 경과 시간, 실행 여부이다.

| 현재 상태 | 조건                             | 처리와 다음 상태                                    |
| --------- | -------------------------------- | --------------------------------------------------- |
| 재생      | 프레임 표시 시간 경과            | 다음 프레임으로 진행                                |
| 재생      | 한 사이클 완료, 완료 횟수 5 미만 | 완료 횟수를 갱신하고 같은 동작의 첫 프레임으로 진행 |
| 재생      | 5번째 사이클 완료                | 마지막 프레임을 유지하고 대기 상태로 전환           |
| 대기      | 1초 경과                         | 다음 동작으로 이동하고 재생 상태로 전환             |
| 대기      | 마지막 동작에서 1초 경과         | 첫 동작으로 돌아가 재생 상태로 전환                 |
| 모든 상태 | 창 닫기 또는 Escape              | 루프 종료 및 자원 정리                              |

좌표를 이미지 상단 기준으로 조사한 경우 pico2d의 하단 기준 좌표로 변환한다. 변환 규칙은 `하단 y = 이미지 높이 - 상단 y - 프레임 높이`로 통일한다.

## 6. 범위에서 제외하는 기능

- 수동 동작 선택, 일시 정지, 배속 조절 등 재생 제어 UI
- 캐릭터 이동 조작, 충돌, 점수 등 게임 기능
- 사운드, 이미지 편집, 애니메이션 내보내기
- 외부 설정 파일, 별도 Python 모듈, 실행 파일 패키징

## 7. 단계별 개발 및 커밋 계획

각 단계는 이전 단계의 결과를 유지하면서 구현하고, 표의 확인 항목을 검증한 뒤 별도 커밋이 가능한 상태로 마무리한다. 전체 구현을 먼저 완성한 뒤 커밋만 분할하지 않는다. 데이터 조사 단계의 결과도 단일 Python 파일의 데이터 또는 주석에 남긴다.

| 단계 | 구현 내용                                          | 완료 확인                            |
| ---- | -------------------------------------------------- | ------------------------------------ |
| 01   | 실행 파일 생성 및 최소 진입점 구성                 | Python 구문 확인 통과                |
| 02   | pico2d 창 열기·닫기 구성                          | 빈 창 실행과 정상 정리 확인          |
| 03   | 기본 이벤트 루프와 종료 입력 처리                  | 창 닫기와 Escape 동작 확인           |
| 04   | 이미지 파일명 정리 및 파일 기준 경로 구성          | 실행 위치가 달라도 같은 경로 계산    |
| 05   | 이미지 로딩과 오류 처리                            | 정상 로딩 및 누락 시 오류 안내 확인  |
| 06   | 원본 이미지 전체를 임시 표시                       | 제공 이미지 정상 표시 확인           |
| 07   | 전체 동작과 소닉 포즈 목록 조사·기록              | 이미지 전체와 목록 대조              |
| 08   | 프레임 데이터 형식과 좌표 변환 함수 구성           | 알려진 영역의 변환 결과 확인         |
| 09   | 첫 동작의 첫 프레임 잘라 그리기                    | 인접 프레임과 문구가 섞이지 않음     |
| 10   | 첫 동작의 전체 프레임 좌표 등록                    | 각 프레임 순서와 영역 확인           |
| 11   | 경과 시간 기반 프레임 재생 구현                    | 첫 동작 1회가 올바른 순서로 재생     |
| 12   | 한 동작의 반복 재생 구현                           | 마지막 프레임에서 첫 프레임으로 연결 |
| 13   | 반복 횟수 추적 및 5회 경계 구현                    | 정확히 5회 완료 시점 식별            |
| 14   | 1초 대기 상태와 마지막 프레임 유지 구현            | 대기 시간 및 종료 입력 응답 확인     |
| 15   | 두 번째 동작 데이터와 동작 전환 구현               | 첫 동작 5회·대기 후 두 번째 시작    |
| 16   | 남은 동작 데이터의 전반부 등록                     | 등록한 각 동작의 프레임 순서 검수    |
| 17   | 남은 동작 데이터의 후반부 및 독립 포즈 등록        | 전체 소닉 동작과 목록 대조 완료      |
| 18   | 마지막 동작에서 첫 동작으로 순환 구현              | 전체 순서가 두 번 이상 이어짐        |
| 19   | 공통 정수 확대 배율과 중앙 배치 구현               | 충분한 크기 및 화면 경계 확인        |

## 8. 수용 기준과 검증 방법

| ID    | 수용 기준                                            | 검증 방법                                                       |
| ----- | ---------------------------------------------------- | --------------------------------------------------------------- |
| AC-01 | Python과 pico2d로 실행되며 실행 코드는 단일 파일이다 | 파일 구성 확인 및 실제 실행                                     |
| AC-02 | 이미지의 모든 소닉 동작과 독립 포즈가 포함된다       | 원본 이미지와 동작·프레임 목록을 영역별 대조                   |

최종 검증에서는 임시 로그가 정상 화면이나 재생 시간을 방해하지 않게 하고, 확인이 끝난 디버그 코드는 정리한다. 이미지 파일이나 개발 환경 문제로 검증하지 못한 항목은 통과 처리하지 않고 미검증 사유를 기록한다.
