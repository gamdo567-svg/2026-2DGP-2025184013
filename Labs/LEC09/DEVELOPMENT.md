# 소닉 애니메이션 뷰어 개발 기록

## 실행

Python과 pico2d가 설치된 환경에서 저장소 루트 기준으로 실행한다.

```powershell
python Labs/LEC09/sonic_animation_viewer.py
```

`Labs/LEC09`에서는 `python sonic_animation_viewer.py`로 실행한다. `sonic-sprite.png`는 스크립트와 같은 폴더에 둔다. Escape 또는 창 닫기로 종료한다.

800 × 600 창에서 15개 동작, 76개 프레임을 9배 확대한다. 기본 프레임 시간은 0.1초이며 동작별로 더 빠른 속도를 적용한다. 각 동작을 5회 재생한 뒤 마지막 프레임을 1초 유지하고 다음 동작으로 이동한다. 전체 순환의 논리적 길이는 41.175초이며 무한 반복한다. 동작명은 원본에 이름이 없어 외형을 기준으로 붙였다.

## 동작 속도와 이동 조정

사용자 피드백에 따라 머리를 감싸는 놀라기 동작과 웅크리기·회전·달리기 동작의 프레임 시간을 줄였다. 걷기는 0.08초, 달리기는 0.06초, 고속 달리기·잔상 달리기는 0.05초, 공중 회전은 0.055초, 머리 감싸기와 웅크리기는 0.06초다. 그 밖의 동작별 수치는 `MOTION_SETTINGS`에 기록되어 있다.

걷기와 달리기는 5회 재생 전체에 걸쳐 왼쪽에서 오른쪽으로 이동한다. 공중 회전은 각 반복에서 상승·착지하면서 가로로 이동한다. 회전 공도 가로로 이동하고 달리기 계열에는 작은 상하 탄성이 적용된다. 대기 중에는 마지막 위치를 유지하며 다음 동작 시작 시 위치를 초기화한다. 이동 거리와 높이는 800 × 600 화면 경계를 넘지 않도록 설정했다.

## 검증 결과

검증 환경: Windows, Python 3.14, 로컬에 설치된 pico2d. 검증일: 2026-10-06.

- Python 구문 검증을 통과했다.
- 15개 동작 각각의 모든 프레임 순서, 5회 반복, 마지막 프레임 유지, 정확한 논리 시간 1초 대기, 다음 동작 초기화를 검증했다.
- 단일 프레임 동작과 전체 두 바퀴를 검증했다. 큰 시간 간격을 한 번 전달한 경우와 0.01초씩 나눠 전달한 경우의 최종 상태가 일치했다.
- 원본 PNG의 알파 픽셀을 대조했다. 소닉 영역(y=38..468)의 모든 불투명 픽셀이 정확히 한 프레임에 포함되고 제목·크레딧 영역은 포함되지 않는다.
- 전체 프레임을 잘라 만든 검수 이미지에서 잘림과 인접 프레임 혼입을 확인하고 수정했다. 9배 확대 후 모든 표시 영역이 창 안에 들어오는 것을 계산으로 검증했다.
- 실제 pico2d 이미지 로딩과 76개 프레임의 그리기를 SDL 비표시 드라이버와 소프트웨어 렌더러에서 검증했다. 이 렌더러 선택은 검증 과정에만 적용했으며 제품 코드는 pico2d 기본 렌더러를 사용한다.
- 누락 이미지와 로딩 오류에 대해 경로를 포함하는 오류 안내 및 창 정리를 검증했다. 두 실행 디렉터리에서도 이미지 경로가 유지된다.
- 창 닫기와 Escape 이벤트를 주입하는 단위 검증을 통과했다. 상태 갱신과 별개로 매 루프에서 이벤트를 처리한다.
- 초기 원본 이미지의 실제 창 표시는 확인했다. 이후 물리적 Escape 입력으로 Computer Use가 중단되어 추가 화면 조작은 하지 않았다.

속도·이동 조정 뒤 15개 동작의 5회 재생과 1초 대기, 두 바퀴 순환, 가로 이동과 공중 회전의 도약·착지, 모든 이동 위치의 화면 경계를 다시 검증했다. 실제 pico2d 창에서도 확대된 회전 공과 머리를 감싸는 프레임이 표시되는 것을 확인했다. 전체 동작을 실시간으로 두 바퀴 관찰하거나 1초 대기의 실제 오차를 측정하지는 않았다.

## 남은 실제 화면 확인

구현과 자동 검증은 완료했으나 아래 항목은 최종 버전의 실제 창에서 확인하지 못했으므로 수용 기준 전체 통과로 표시하지 않는다.

1. 약 106초 동안 두 바퀴를 관찰하여 동작별 자연스러움과 불필요한 위치 흔들림 확인.
2. 실제 화면에서 1초 대기의 오차가 ±0.1초 이내인지 측정.
3. 재생 중과 대기 중 각각 Escape 및 창 닫기로 정상 종료 확인.

이는 PRD의 AC-04, AC-05, AC-06, AC-07, AC-08 중 실제 화면 관찰·실시간 측정 부분에 해당한다. 자동 상태 검증과 정적 프레임 검수는 통과했지만 해당 관찰을 대신한 것으로 간주하지 않는다.
