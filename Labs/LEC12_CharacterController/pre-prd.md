Idle 상태에서 'a'키를 누르면 소년은 자동 무적 런 상태가 되어 키조작 없이도 계속 좌우로 이동할수 있다.

소년은 속도가 빨라지고, 크기가 확대되어야한다.

화면의 좌우측 벽에 닿으면 방향이 자동으로 전환되어야한다.

자동 무적 런 상태에서 5초가 경과하면 Idle 상태로 돌입한다.

자동 무적 런 상태에서 방향키가 눌리면 무한 런이 취소되고 눌린 방향으로 움직이는 원래의 Run으로 돌아간다.

중요사항

1. 반드시 AutoRun 상태클래스를 추가하여 구현해야한다.
2. 제출툴에 상태다이어그램을 함께 제출해야한다.

기능 기준

'a'를 누르면 auto run 상태 이동

5초 이상 경과하면 idle 상태로 복귀

auto run 모드에서 속도가 빨라지고 크기가 커짐

auto run 모드에서 좌우측 끝에 자동방향전환
